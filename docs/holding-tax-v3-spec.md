## 2. 재산세 (행 7~16)

### 2.1 과세표준 — **과세표준상한제** (행 9)

```
B9 = IF(RIGHT(B6,2)="주택",
        MIN(B7*B8, B19*B8 + B7*B8*5%),
        B7*B8)
```

- `B7` 시가표준액, `B8` 공정시장가액비율, `B19` 전년도 시가표준액
- **주택일 때만** 상한을 적용한다. 건축물·토지는 `시가표준액 × 공정비율`
- 상한율 **5%**
- 2027·2028도 같은 수식 (`K9`, `T9`)

> 지방세법 §110③ · 시행령 §109의2 와 일치함을 법제처 조문으로 확인했다.
> **현재 우리 엔진에는 이 상한이 없다.** 반드시 넣는다.

### 2.2 전년도 과세표준 (행 19)

```
B19 = B7          (2026: 자기 자신)
K19 = B7          (2027: 2026년 시가표준액)
T19 = K7          (2028: 2027년 시가표준액)
```

### 2.3 세율 (행 10)

```
B10 {배열} = IF(AND(B6="1세대1주택", B7<=9*10^8),
                INDEX(t!$D$3:$D$6, MATCH(TRUE, B9<=t!$A$3:$A$6, 0)),
                INDEX(t!$B$3:$B$6, MATCH(TRUE, B9<=t!$A$3:$A$6, 0)))
```

- 1세대1주택 **이고** 시가표준액 ≤ 9억일 때만 특례세율(D열)
- 아니면 표준세율(B열)
- 주택소계 열(`O10`, `X10`)은 조건 없이 항상 표준세율

### 2.4 산출세액 (행 11)

```
B11 = B9*B10 - VLOOKUP(B10,
        IF(AND(B6="1세대1주택", B7<=9*10^8), t!$D$2:$E$6, t!$B$2:$C$6),
        2, 0)
```

### 2.5 재산세액 (행 12)

```
B12 = B11
```

### 2.6 도시지역분 (행 13)

```

```

**과세표준(행 9)에 곱한다.** 재산세액이 아니다.

### 2.7 지역자원시설세 (행 14)

건축물 열에만 값이 있다 (`G14`, `P14`, `Y14`). 주택 열은 비어 있다.

## 3. 종합부동산세 (행 36~49)

### 3.1 주택공시가격 (행 36)

주택소계 과세표준을 쓴다 (`B36 = 2,400,000,000` = `F9`).

### 3.2 공제금액 (행 37)

**2026:**
```
B37 = IF(B$6="1세대1주택", 12*10^8, 9*10^8)
```

**2027·2028:**
```
K37 = IFERROR(
        IF(K$6="1세대1주택",
           IF(K24="거주", 1400000000, 900000000),
           400000000 + 500000000 * OFFSET(J7, 0, MATCH("거주", $K24:$N24, 0)) / O7),
        4*10^8)
```

- 1세대1주택 거주 **14억** / 비거주 **9억**
- 다주택: **4억 + 5억 × (거주 중인 주택의 시가표준액 / 주택소계 시가표준액)**
- 거주 주택이 없으면 `IFERROR` 로 **4억**

### 3.3 공제초과금액 (행 38)

```
B38 = B36 - B37
```

### 3.4 공정시장가액비율 (행 39) — 상수

| | 2026 | 2027 | 2028 |
|---|---|---|---|
| 거주용1주택 | 0.6 | 0.7 | 0.7 |
| 비거주1,2주택 | 0.6 | 0.7 | 0.7 |
| **3주택이상** | 0.6 | 0.7 | **0.8** |

### 3.5 과세표준 (행 40)

```
B40 = B38 * B39                          (2026)
K40 = IF(K38>0, K38*K39, 0)              (2027·2028 — 음수면 0)
```

### 3.6 세율 (행 41)

```
B41 {배열} = IF(B29="기본세율",
                INDEX(t!$M$3:$M$9, MATCH(TRUE, $B$40<=t!$L$3:$L$9, 0)),
                INDEX(t!$O$3:$O$9, MATCH(TRUE, $B$40<=t!$L$3:$L$9, 0)))

K41 {배열} = INDEX(t!$M$13:$M$19, MATCH(TRUE, K40<=t!$L$13:$L$19, 0))   1,2주택
M41 {배열} = INDEX(t!$O$13:$O$19, MATCH(TRUE, M40<=t!$L$13:$L$19, 0))   3주택이상
T41 {배열} = INDEX(t!$M$23:$M$29, MATCH(TRUE, T40<=t!$L$23:$L$29, 0))   2028 단일표
```

`B29 = IF(B28<=2, "기본세율", "중과세율")` — 주택수 2 이하면 기본.

### 3.7 종합부동산세액 (행 42)

```
B42 = B40*B41 - VLOOKUP(B41, IF(B29="기본세율", t!$M$2:$N$9, t!$O$2:$P$9), 2, 0)
K42 = K40*K41 - VLOOKUP(K41, t!$M$13:$N$19, 2, 0)
M42 = M40*M41 - VLOOKUP(M41, t!$O$13:$P$19, 2, 0)
T42 = T40*T41 - VLOOKUP(T41, t!$M$22:$N$29, 2, 0)
```

### 3.8 공제할재산세액 (행 43)

```
B43 = F12 * (B40 * 60% * F10) / F11
K43 = O12 * (K40 * 60% * O10) / O11
T43 = X12 * (T40 * 60% * X10) / X11
```

- `F12`/`O12`/`X12` = **주택소계 재산세액**
- `F10`/`O10`/`X10` = **주택소계 세율**
- `F11`/`O11`/`X11` = **주택소계 산출세액**
- **`60%` 는 상수다.** 1세대1주택의 43~45% 를 쓰지 않는다.

> **60% 로 확정 (2026-08-11, 세무사 확인).** 아래 §6 참조. 다시 열지 않는다.

### 3.9 산출세액 (행 44)

```
B44 = B42 - B43                          (2026 — 음수 보정 없음)
K44 = IF(K42-K43<0, 0, K42-K43)          (2027·2028)
```

### 3.10 세액공제 (행 45)

**공제율 산정:**
```
보유기간   K26 = B26+1           T26 = K26+1
보유공제   K27 = IF(K$6="1세대1주택", IF(K26>=15,25%, IF(K26>=10,20%, IF(K26>=5,10%, 0))))
거주기간   K30 = (입력)          T30 = K30
거주공제   K31 = IF(AND(K$6="1세대1주택", K24="거주"),
                    IF(K30>=15,50%, IF(K30>=10,40%, IF(K30>=5,20%, 0))))
연령       K32 = B32+1           T32 = K32+1
연령공제   K33 = IF(K$6="1세대1주택", IF(K32>=70,40%, IF(K32>=65,30%, IF(K32>=60,20%, 0))))
```

> `IF` 에 else 절이 없다. 1세대1주택이 아니면 `FALSE` 를 반환하고
> `SUM`/`MAX` 안에서 0 으로 취급된다.

**공제액:**
```
2026   B45 = B44 * C45                                            (C45 = 0)
2027   K45 = MIN(8000000, MIN(80%, SUM(K33, MAX(K27, K31))) * K44)
2028   T45 = MIN(6000000, MIN(80%, SUM(T33, MAX(T27, T31))) * T44)
```

**2027·2028 모두 `연령공제 + MAX(보유공제, 거주공제)`, 합계 80% 상한, 금액 한도 800만/600만.**

> 사용자 지시에 따라 이 수식을 그대로 구현한다.
> 현재 우리 엔진은 2028년에 보유공제를 없애고 거주공제만 쓴다 — **바꾼다.**

### 3.11 세부담상한초과세액 (행 46)

**2027·2028 — 보유 시트 내부 계산:**
```
K46 = IF(SUM(K$12*K25, K44) > SUM(B$12*K25, B47) * 200%,
         SUM(K$12*K25, K44) - SUM(B$12*K25, B47) * 200%,
         0)
```

- 당해연도 = `당해 재산세액 × 보유지분 + 당해 종부세 산출세액`
- 전년도   = `전년 재산세액 × 보유지분 + 전년 종합부동산세(행 47)`
- 상한비율 **200%**
- `T46` 은 전년으로 2027(`K12`, `K47`)을 쓴다

**2026 — 숨김 시트 위임:** `B46 = 세부담상한초과세액!B23` → **미결 ②**

## 4. 세부담상한 상세 알고리즘 (숨김 시트 `세부담상한초과세액`)

2026년 `B46` 이 참조하는 20단계다. `B`열 = 2026 주택, `G`열 = 2027 주택.

| 단계 | 이름 | 수식 |
|---|---|---|
| ① | 감면 후 공시가격 | (입력) |
| ② | 공제금액 | `IF($B1="1세대1주택", 1200000000, 900000000)` |
| ③ | 공정시장가액비율 | `0.6` |
| ④ | 종부세 과세표준 | `(①-②)*③` |
| ⑤ | 세율 | `IF(B2="기본세율", INDEX(t!M3:M9,…), INDEX(t!O3:O9,…))` |
| ⑥ | 재산세 공제 전 종부세액 | `④*⑤ - VLOOKUP(⑤, 누진공제표, 2, 0)` |
| ⑦ | 해당연도 재산세액 | **끊김** |
| ⑧ | 과세표준 표준세율 재산세액 | `(① - IF(1세대1주택,12억,9억)) * 60% * 0.4%` |
| ⑨ | 총표준세율 재산세액 | `①*60%*t - VLOOKUP(t, t!B2:C6, 2, 0)` |
| ⑩ | 공제할 재산세액 | `⑦*⑧/⑨` |
| ⑪ | 1세대1주택 세액공제액 | **끊김** |
| ⑫ | 세부담상한 전 종부세액 | `⑥-⑩-⑪` |
| ⑬ | 작년 재산세 | (입력) |
| ⑭ | 작년 종합부동산세 | (입력) |
| ⑮ | 합계 | `⑬+⑭` |
| ⑯ | 상한비율 | **2026: 1.5 · 2027: 2** |
| ⑰ | 세부담상한액 | `⑮*⑯` |
| ⑱ | 해당연도 총세액상당액 | `⑦+⑫` |
| ⑲ | 세부담상한액 | `=⑰` |
| ⑳ | **세부담상한초과세액** | `IF(⑱>⑲, ⑱-⑲, 0)` |

토지도 같은 구조로 종합합산(C·H열)·별도합산(D·I열)이 있다.
종합합산 ⑧ = `④*0.5%`, 별도합산 ⑧ = `④*0.4%`, 공정비율 ③ = `1`.

## 5. 손상·모순 지점과 판정

전사하다 보니 v3 파일 자체가 손상·모순된 곳이 7 군데 있다.

**사용자 판정 (2026-08-10): 「본 시트(`보유`)가 무조건 맞다.」**

그 원칙으로 6 개가 확정됐다. 남은 하나(2026년 세부담상한)는 본 시트가 손상된
숨김 시트를 가리키고 있어 본 시트만으로 풀리지 않는다 — **현행 구현을 그대로 두고
나머지를 먼저 구현한다.**

| # | 항목 | 판정 |
|---|---|---|
| ① | 주택 지역자원시설세 | **매기지 않는다** — 본 시트 주택 열이 비어 있다 |
| ② | 2026년 세부담상한 | **미결 · 현행 유지** — 유일하게 안 풀린 항목 |
| ③ | 2027 종부세 공정비율 | **0.7** — 본 시트 `K39` |
| ④ | 소유자2 블록 | **구현하지 않는다** — 범위 밖 |
| ⑤ | 행 21 전년도 종합부동산세 | **무시** — 본 시트가 안 쓴다 |
| ⑥ | 재산세 특례세율 9억 조건 | **전 열 적용** |
| ⑦ | 2028 세액공제 | **`연령 + MAX(보유, 거주)`** — 본 시트 `T45` |

아래는 각 판정의 근거다.

### ① 주택 지역자원시설세 — **매기지 않는다**

행 14가 **건축물 열(`G14`, `P14`, `Y14`)에만** 있고 주택 열은 비어 있다.
그런데 `재산세납부액 = SUM(행12:행15)` 이라 주택 열은 0 으로 합산된다.
세율표(`t!A26:C32`)는 존재한다.

- 엑셀대로면 **주택은 지역자원시설세 없음**
- 실제 지방세법상 주택에도 소방분 지역자원시설세가 붙는다

**판정: 본 시트대로 주택에는 매기지 않는다.** 건축물에만 §1.8 세율표를 쓴다.
지방세법상 주택에도 소방분이 붙지만, 본 시트가 안 매기므로 따르지 않는다.

### ② 2026년 세부담상한 — **미결. 현행 구현 유지**

`B46 = 세부담상한초과세액!B23` 인데 그 시트가 `#REF!` 다.
끊긴 곳은 ⑦(해당연도 재산세액), ⑨의 세율 참조, ⑪(1세대1주택 세액공제액) —
**전부 `증여!#REF!` / `양도!#REF!`**, 즉 삭제된 다른 시트를 가리킨다.

구조(①~⑳)는 온전하고, 끊긴 값들은 **우리가 이미 계산하는 값**이다.
⑦ = 행 12, ⑪ = 행 45, ⑨의 세율 = `F10`.

- **(가)** 숨김 시트 ①~⑳ 구조를 복원해 2026년에 쓴다 (상한비율 1.5)
- **(나)** 2027·2028의 `K46` 인라인 수식을 2026에도 쓰되 비율만 150% 로 한다

두 방식은 **결과가 다르다.** ⑱은 `⑦+⑫`(재산세 전액 + 종부세)이고
`K46`의 당해연도는 `재산세액×보유지분 + 종부세`다 — **지분 곱이 붙느냐가 다르다.**

**판정 보류.** 본 시트 `B46` 이 손상된 숨김 시트를 가리키므로 「본 시트가 맞다」로
풀리지 않는 유일한 항목이다. **2026년은 현재 엔진 동작(150%)을 그대로 두고**
2027·2028 만 `K46`/`T46` 수식에 맞춘다. 이 항목은 별도 태스크로 남긴다.

### ③ 2027 종부세 공정비율 — **0.7**

`세부담상한초과세액!G6 = 0.6` vs `보유!K39 = 0.7`.
숨김 시트가 낡은 것으로 보이나 **엑셀에는 두 값이 다 있다.**

**판정: 본 시트 `K39 = 0.7`.** 숨김 시트 `G6 = 0.6` 은 낡은 값으로 버린다.

### ④ 소유자2 블록 — **구현하지 않는다**

```
K55 = t!M6+1      → 1.013      (t!M6 은 세율 0.013 이다)
T55 = t!#REF!+1   → #REF!
```

세율 셀을 보유기간으로 참조하고 있다. 명백한 손상.
소유자1은 `K26 = B26+1` 로 정상.

**판정: 범위 밖.** 우리 앱은 물건별 `ownershipShare` 단일 소유자 모델이다.
공동명의 2 인 각각의 세액 산정은 지금 제품에 없는 기능이므로 구현하지 않는다.

### ⑤ 행 21 전년도 종합부동산세 — **무시**

`F21 = 10,338,996` 은 값이 박혀 있으나 `O21`(2027), `X21`(2028)은 `#REF!`.
`K46` 은 대신 `B47`(2026 종부세)을 참조하므로 실사용에는 지장 없다.

**판정: 무시.** 본 시트 `K46` 이 행 21 대신 `B47` 을 참조하므로 쓰이지 않는 잔재다.

### ⑥ 재산세 특례세율 9억 조건 — **전 열 적용**

```
B10 = IF(AND(B6="1세대1주택", B7<=9*10^8), 특례, 표준)   ← 조건 있음
C10 = IF(C6="1세대1주택", 특례, 표준)                    ← 조건 없음
D10, E10 도 동일
```

2027·2028(`K10`~`N10`, `T10`~`W10`)은 전부 `AND(…, <=9억)` 이 있다.
2026 C~E 가 갱신 누락으로 보인다.

**판정: 전 열에 적용한다.** 본 시트의 `B10` 과 2027·2028 전 열이 조건을 갖고 있고,
`C10`~`E10` 만 갱신 누락이다.

### ⑦ 2028년 세액공제 — **`연령 + MAX(보유, 거주)`**

`T27`/`T31`/`T33` 은 `IF(T6="1세대1주택", …)` 인데 v3 시나리오의 `T6="주택"` 이라
셋 다 `FALSE` 로 죽어 `T45 = 0` 이다. 즉 저자가 이 경로를 실행해 본 적이 없다.
수식 구조는 2027 열의 복사본이고 한도만 800만 → 600만이다.

사용자 지시에 따라 **엑셀 수식 그대로** `연령 + MAX(보유, 거주)` 로 구현한다.
(참고: 개편안 p64 를 인용한 우리 `docs/tax-rules-spec.md` §5.2 는 *"'28년~ 거주공제만"*
이라고 적고 있어 서로 다르다. 지시대로 엑셀을 따르되 이 차이를 기록해 둔다.)

## 6. 구현 시 유지할 것

- **반올림**: 엑셀은 반올림하지 않는다. 우리 엔진의 `roundTaxAmount` 적용 지점을
  바꾸지 않는다. 엑셀 대조 시 소수점 차이는 이 때문이다.
- **주택소계**: 종부세의 `공제할재산세액`은 개별 물건이 아니라 **주택소계**
  (`F10`/`F11`/`F12`)를 쓴다. 물건별로 계산하면 값이 달라진다.
- **보유지분**: 세부담상한(`K46`)에만 곱해진다. 재산세·종부세 본 계산에서
  지분을 어디에 곱하는지는 엑셀 행 25 를 그대로 따른다.

## 6. 공제할 재산세액의 공정시장가액비율 — **60% 확정**

**결론: 60%. 1세대1주택이어도 43/44/45% 를 쓰지 않는다.**
2026-08-11 세무사 확인. 현재 구현이 이미 60% 이므로 코드 변경 없음.

이 항목은 한 번 뒤집혔다 다시 확정된 것이라 근거를 남긴다.

### 조문 체인

```
종부세법 §9③              주택분 과세표준에 대한 재산세액을 종부세액에서 공제
  └ 종부세법 시행령 §4조의3①  공제할재산세액 계산식
      └ 「지방세법 시행령」 제109조제1항제2호에 따른 공정시장가액비율
```

지방세법 §110③ 은 **과세표준상한** 조항이지 공제할 재산세액과 무관하다.
지방세법 본문 어디에도 「공제할 재산세」 문구는 없다(전문 검색 확인).

### 왜 60% 인가 — 단서의 적용 범위

지방세법 시행령 §109①2 의 구조:

```
[본문] 주택: 시가표준액의 100분의 60.
[단서] 다만, 2026년도에 납세의무가 성립하는 재산세의 과세표준을 산정하는 경우
       … 1세대 1주택 … 에 대해서는  43% / 44% / 45%
```

단서가 **「재산세의 과세표준을 산정하는 경우」로 한정**된다. 공제할 재산세액을
구하는 것은 재산세 과세표준을 산정하는 일이 아니므로 단서가 걸리지 않고
**본문 60%** 가 적용된다.

### 국세청 간이계산기는 45% 로 계산한다 — 따르지 않는다

`docs/종합합부동산세 간이세액계산 결과 조회.pdf` (2026-08-11 조회) 기준:

```
⑦ 공제할 재산세액           3,706,559
  = 종부세과표 2,059,200,000 × 45% × 0.4%   (60% 면 4,942,080, 차이 1,235,521)

전년도(2025, 공시 3,088,000,000) 총세액상당액
  60% → 11,137,680        45% → 11,817,360        국세청 역산 11,817,361
```

두 해가 독립적으로 45% 를 가리키지만, 조문 해석이 60% 이고 실무 기준(v3.1 엑셀
48행)도 60% 다. **60% 를 따른다.**

### 헷갈리기 쉬운 세 비율

| | 근거 | 값 |
|---|---|---|
| 종부세 공정비율 | 종부세법 시행령 §2조의4 | 60% (2027~ 개편안 70%·80%) |
| 재산세 공정비율 | 지방세법 시행령 §109①2 | 1세대1주택 43/44/45 · 그 외 60 |
| **공제할재산세액의 비율** | §4조의3① → §109①2 **본문** | **60% 고정** |

2026년 일반주택에서는 셋이 모두 60% 라 구분이 드러나지 않는다. 갈라지는 것은
1세대1주택(재산세 45%)과 2027년 이후(종부세 70%) 두 경우다.
