## ⚠️ 차이점

### 차이 1: 세부담상한의 전년도 종부세상당액 기준

**위치**: 공동보유 row 27 수식 vs 코드 `priorComprehensiveTaxKind`

| 연도 | 코드 | 엑셀 v3.5 |
|---|---|---|
| 2026 | `'calculated'` = 산출세액(row 55) | **row 57** (세액공제 후) |
| 2027+ | `'final'` = 최종세액(row 59, 상한반영후) | **row 57** (세액공제 후, 상한반영 전) |

- 엑셀 수식: `F27 = F57`, `N27 = N57`, `V27 = V57` — 전 연도 일관되게 row 57 참조.
- 코드: 2026은 산출세액(세액공제 전), 2027+는 최종세액(세부담상한 반영 후)을 사용.
- **영향**: 1세대1주택 세액공제가 있는 경우 결과 차이 발생. 3주택 등 세액공제=0인 경우에는 차이 없음.

### 차이 2: 종부세 납부세액 하한 (2026년)

**위치**: 공동보유 row 59 수식 vs 코드 `COMPREHENSIVE_PAYABLE_TAX_MINIMUM_2026`

| 항목 | 코드 | 엑셀 v3.5 |
|---|---|---|
| 2026 납부세액 하한 | 0원 (`= 0`) | 없음 (row 57 − row 58, MAX 없음) |
| 2027+ | 없음 (`= null`) | 없음 (row 57 − row 58, MAX 없음) |

- 코드의 `COMPREHENSIVE_PAYABLE_TAX_MINIMUM_2026 = 0`은 v3 엑셀 기준으로 설정된 값.
- v3.5 엑셀은 2026에도 MAX(0,...) 미적용.
- **영향**: 공제할재산세액 > 종부세액인 극단적 경우에만 차이. 실무적으로 발생 가능성 낮음.

## 비교 범위 밖 참고사항

### 엑셀 "전년도" 열의 세액공제 금액한도

공동보유 시트의 2027년 전년도 열(N56)에 `MIN(8000000, ...)` 수식이 적용되어 있으나, 전년도(=2026) 규칙에는 금액한도가 없어야 함. 코드의 `amountCap: null`(2026)이 정확하며, 엑셀의 전년도 열 수식이 해당 연도 규칙을 정확히 반영하지 않는 것으로 보임. 이는 파라미터가 아닌 수식 로직 차이.
