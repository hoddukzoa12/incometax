## 0. 왜 이 사이트가 가장 중요한 참조인가

[호갱노노](./hogangnono-analysis.md)와 아실은 **매물·시세 서비스**다. 세금은 부가 기능이거나
아예 없다(아실은 `세금`·`보유세`·`종부세`·`양도세` 전부 0건).

**부동산계산기.com은 우리와 같은 종류의 제품이다.** 그리고 **이미 2026 세제개편안을
반영해 두었다.** 우리가 하려는 일을 먼저 한 곳이므로, UI 참조가 아니라 **계산 검증의
교차 원천**으로 쓴다.

## 2. Q1이 여기서 해결됐다 — 두 제도를 섞지 말 것

세무사 확인 목록의 Q1(재산세 1주택 특례비율에 9억 상한이 있는가)이 **이 사이트의 해설로
결론났다.** 공시 20억 1주택 계산 결과에 두 문장이 나란히 출력된다:

> *"1세대 1주택자 공시가격(2,000,000,000) **6억 초과 공정시장가액비율 45% 적용**"*
> *"공시가격이 **9억원을 초과하여 1세대1주택 재산세 감면 특례(2021~2026년)이 적용되지 않았습니다**"*

**별개의 두 제도다.**

| | 9억 조건 |
|---|---|
| 공정시장가액비율 43 / 44 / 45% | **없다.** 공시 20억도 45% |
| 재산세 감면 **특례세율** 0.05~0.35% | **있다.** 9억 초과면 미적용 |

`260804 3단계프로그램.xlsx` D7이 **두 제도의 조건을 섞었다.** 우리 §2.1이 맞다.
→ Q1은 [tax-accountant-questions.md](./tax-accountant-questions.md)에서 해결 처리.

## 3. 입력 설계 — 우리가 배울 곳

기본 화면은 **체크박스 몇 개와 금액 하나**가 전부다.

```
□ 법인     ☑ 1세대1주택자     □ 세부담상한     □ 26년 세제개편안 선반영
□ 만60세 이상      □ 5년 이상 보유
□ 기준연도 등 기준값 조정                          ← 고급 옵션 접힘

공시가격 [        ] 만원    □ 도시지역   □ 조정대상지역   □ 공동명의
                                                      [ 자산 추가 ]
```

**생년월일도, 취득일도, 날짜 입력이 하나도 없다.** 흔한 경우는 `만60세 이상`·`5년 이상 보유`
체크박스로 끝내고, 정밀한 값이 필요한 사람만 고급 옵션을 연다.

고급 옵션(`기준연도 등 기준값 조정`)을 펼치면 숫자 입력이 나온다:

| 필드 | 뜻 |
|---|---|
| `baseYear` | 기준연도 |
| `age` · `long` · `residencePeriod` | 나이 · 보유기간 · 거주기간 |
| `propTaxFairRate` · `synthTaxFairRate` | 재산세·종부세 공정시장가액비율 (미입력 시 기본값) |
| `synthTaxDeduct` | 종부세 공제금액 |
| `preSynthTax` · `property[n][prePropTax]` | **전년도** 종부세·재산세 (세부담상한용) |

**이것이 progressive disclosure가 제대로 된 모습이다.** 체크박스가 흔한 경우를 덮고,
숫자 필드가 정밀한 경우를 덮고, 기본값이 있어 비워도 계산된다.

> 우리 계산 화면은 물건마다 `지분·취득일·거주기간·거주여부·지역구분` 5개 필드를 요구해
> 물건 3채면 16개 입력이 됐다. 여기는 **체크박스 2개로 같은 일**을 한다.

**개편안을 토글로 둔 것도 눈여겨볼 만하다.** 우리는 현행/'27/'28 3열 비교로 풀었는데,
그쪽은 `26년 세제개편안 선반영` 체크 + `기준연도` 입력으로 같은 비교를 만든다.
`세부담상한`도 토글이라 켜고 끄며 효과를 볼 수 있다.

## 3-a. 토글 전수 검증 (2026-08-05 실측)

체크박스를 하나씩 뒤집어 결과 행을 비교했다. 기준 케이스는
`2027년 · 공시 25억 · 1세대1주택 · 거주 · 도시지역 · 개편안 ON`.

| 토글 | 효과 |
|---|---|
| **법인** | 재산세 공정비율 45→60%, **종부세 공제 0원** (종부세 61,250,000) |
| **1세대1주택자** | 끄면 재산세 공정비율 45→**60%**, 종부세 공제 14억→**9억** |
| **거주** | 끄면 종부세 공제 14억→**9억**. 재산세는 무변화 |
| **도시지역** | 끄면 도시지역분 제외 (총액 −1,575,000) |
| **조정대상지역** | 1세대1주택에서는 **무효**. '28년·다주택에서 종부세 공정비율 70→**80%** |
| **공동명의** | `재산세 지분` · `도시지역분 지분` 행이 추가. 전체 산출 후 지분 곱 |
| **26년 개편안 선반영** | **종부세만** 바꾼다 — 공제금액·공정비율·세율 세트. 재산세 4개 항목 무변화 |

**조정대상지역이 우리 §3.3과 정확히 일치한다.** 1세대1주택자는 조정대상지역이어도 항상
70%이고, 3주택 이상 또는 조정대상지역(1주택 제외)만 '28년 80%다. 실측 —
과세표준 245,000,000(÷0.7) → 280,000,000(÷0.8), 원 과세대상 350,000,000 동일.

**개편안 토글이 재산세를 안 건드리는 것도 확인됐다.** 앞서 PDF 250쪽 전문에서
"재산세를 개정하는 조항이 없다"고 확인한 것과 같은 판단이다.

### 토글이 입력 필드를 연다 — 배울 구조

```
모두 끈 상태      공시가격 하나뿐
세부담상한 켜면    전년도 종부세 · 전년도 재산세 · 전년도 도시지역분
기준값 조정 켜면   기준연도 · 종부세 공제금액 · 재산세 공정비율 · 종부세 공정비율
만60세 이상       필드 없음 — 체크 자체가 값
5년 이상 보유     필드 없음 — 체크 자체가 값
```

**기본 화면의 입력은 공시가격 하나다.** 나머지는 필요할 때만 나타난다.

### 그쪽이 못 하는 것 — 세액공제 구간

`age` · `long` · `residencePeriod` 필드가 DOM에 있으나 **어떤 토글로도 화면에 노출되지
않는다.** 세액공제는 `만60세 이상`·`5년 이상 보유` 체크박스 둘로만 조작된다.

| | 부동산계산기 | 우리 |
|---|---|---|
| 연령공제 | 60세 20%만 | 60/65/70 → 20/30/40% |
| 기간공제 | 보유 5년만 | 5/10/15년, `MAX(보유, 거주)` |
| 거주기간 인정 특례 | 없음 | §5.2-a 구현 완료 |

**입력 설계는 그쪽이 낫고, 세법 커버리지는 우리가 넓다.**

## 3-b. 재산세에도 세부담상한이 있다 — 우리에게 없는 제도

세부담상한을 켜고 전년도 값을 넣으면 재산세 쪽에 두 행이 추가된다:

```
6   전년도 세액       2,610,000   입력값
7   세부담상한        3,393,000   공시가격 6억원 초과, 전년도 세액의 130% 상한 적용
```

**세액 130% 상한이다.** 공시가격 구간별로 상한율이 다르다(6억 초과 130%).
도시지역분에는 **별도 상한**이 걸린다 — 해설: *"산출 도시지역분이 세부담 상한액인
1,638,000를 초과하지 않아 세부담 상한이 적용되지 않았습니다."*

> ✅ **2026-08-05 조문 확인 — 두 제도가 다 존재한다.**
> 엑셀 D8의 `MIN(공시×비율, 전년과표×비율 + 5%)`는 **지방세법 §110③ 과세표준상한**이고,
> 여기 보이는 130%는 **§122 세액상한**(주택 단서)이다. 서로 다른 단계에 걸리며
> 시행령 §5①제1호가 *"과세표준상한을 적용한 후의 세액"*이라 하므로
> **① 과세표준상한 → ② 세율 → ③ 세액상한** 순이다.
>
> §122의 *"제112조제1항 각 호 … 각각의 세액"*이 도시지역분 별도 상한의 근거다.
> 상세는 [tax-rules-spec.md §2.4](./tax-rules-spec.md).

종부세 세부담상한의 기준액은 표시된 산식에서 읽힌다:

```
세부담상한 적용 = 전년도 세부담(2,610,000 + 1,270,000) × 200% − 3,393,000
                              ↑ 전년 재산세 본세  ↑ 전년 종부세
```

전년 도시지역분(1,260,000)은 들어가지 않았다. **본세 + 종부세**다.

✅ **조문으로 확정됐다.** 종부세법 시행령 §5①제1호는 「지방세법」 **§112①제1호**(일반 재산세액)로
한정하고, §5②제1호는 **§112①제2호(도시지역분)를 명시적으로 제외**한다.
이 계산기의 동작이 조문과 일치한다.

## 7. 남은 확인

**공시 9억 이하 1주택**으로 한 번 더 돌려 특례세율(0.05~0.35%)이 적용될 때
재산세 중복분이 우리와 같은지 봐야 한다. §1의 산식 형태 차이가 그 구간에서만 드러난다.
골든 케이스 H6(공시 9억 · 재산세 특례세율 경계)이 그 자리다.
