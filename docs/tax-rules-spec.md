# 세법 룰 명세

`src/rules/`가 담아야 할 값과 구조를 정의한다. **이 문서가 세법 값의 출처다** —
Codex는 개편안 PDF를 직접 뒤지지 말고 여기를 옮긴다.

기대값은 [golden-cases.md](./golden-cases.md)에 있다. 규칙은 [AGENTS.md](../AGENTS.md).

> **근거** 2026년 세제개편안 상세본 (재정경제부, '26.8.3.).
> 이하 `p57` 등은 **문서 페이지**이며, PDF 페이지 = 문서 페이지 + 13이다.
>
> **개편안은 국회 통과 전 정부안이다.** 심의 과정에서 바뀔 수 있으므로 연도별로 분리해
> 관리하고, 확정 시 이 문서를 먼저 고친 뒤 코드를 따라 고친다.

## 0. 출처 우선순위 (2026-08-05 확정)

세법 값의 출처가 둘이다. 충돌하면 **PDF가 이긴다.**

```
1순위  세제개편안 PDF (재정경제부 '26.8.3.)          ← 원문
2순위  260804 3단계프로그램.xlsx (세무법인 리치)      ← 실무 해석
```

- **PDF에 값이 있으면 PDF를 쓴다.** 엑셀이 다르면 엑셀이 틀린 것으로 본다
- **PDF에 없는 것은 엑셀 해석을 따른다.** 개편안은 바뀌는 것만 담으므로,
  계산 구조·기존 규정 해석은 엑셀이 유일한 실무 근거다
- 어느 쪽에도 없으면 **추측하지 말고 `ask`** 한다

### 이 규칙으로 정리된 건

| 항목 | 엑셀 | PDF | 채택 |
|---|---|---|---|
| 1세대1주택 종부세 세율 | 현행 표 (12억 초과 1.0%) | '27년부터 `2주택 이하` 표 (1.3%) — **1세대1주택 별도 표 없음** (p63) | **PDF** |
| 세액공제 금액 한도 | 800만원 고정 | '27년 800만 → '28년 이후 **600만** (p64) | **PDF** |
| 세부담상한 기준액 | 재산세 **본세**만 | 정의 없음 (비율만 개정, p65) | **엑셀 = 조문 일치** ✅ |

> **셋째 항목은 2026-08-05 조문으로 확정됐다.** 종부세법 시행령 §5①제1호는 기준액을
> 「지방세법」 **§112①제1호**(일반 재산세액)로 한정하고, §5②제1호는 **§112①제2호(도시지역분)를
> 명시적으로 제외**한다. 지방교육세는 지방세법상 별도 세목이라 애초에 "재산세액"이 아니다.
> **엑셀 해석이 조문과 일치한다.** 상세는 [golden-cases.md](./golden-cases.md) H14.
>
> **PDF에 없다고 엑셀을 무조건 따르지는 않는다.** 원천 법령을 조회할 수 있으면 그것이
> 엑셀보다 앞선다. 법제처 국가법령정보 API를 `.mcp.json`으로 연결해 두었다.

## 1. 설계 원칙

### 조건은 키로, 값은 테이블로 (R1)

세법 분기를 `if`로 표현하지 않는다. 조건 조합을 키로 만들어 테이블을 조회한다.

```ts
type HouseholdKind = 'oneHouse' | 'multiHouse'   // 1세대1주택자 여부
type Residency     = 'residing' | 'nonResiding'  // 해당 주택 거주 여부
type AreaKind      = 'adjusted' | 'general'      // 조정대상지역 여부
type TaxYear       = 2026 | 2027 | 2028 | 2029   // 2026 = 현행
```

### 값에는 출처를 단다 (R2)

근거 없는 숫자는 리뷰 반려다.

```ts
/** 종부세 기본공제 — 개편안 p61, '27.1.1. 이후 납세의무 성립분부터 */
export const BASIC_DEDUCTION_2027 = { /* ... */ } as const
```

### 누진세율 표현

모든 세율표는 동일한 형태를 쓴다. `누진공제`를 미리 계산해 둔다.

```ts
interface Bracket {
  upTo: number                  // 이 값 이하 구간 (최상단은 Infinity)
  rate: number                  // 세율 (0.007 = 0.7%)
  progressiveDeduction: number  // 누진공제액 (원)
}
// 세액 = max(0, 과세표준 × rate − progressiveDeduction)
```

## 2. 재산세 — **개편 대상 아님**

개편안에 재산세 개정 내용이 없다. 현행 지방세법이 '26~'29년 전 기간에 그대로 적용된다.

> ⚠️ 아래 값은 개편안이 아니라 **현행 지방세법**에서 온 것이다. 수치 자체는
> propertytax.co.kr 운영 서버 응답과 대조해 검증했으나(golden-cases H1),
> **조문 번호는 별도 확인이 필요**하다. 구현 시 조문을 인용하려면 법령을 직접 확인할 것.

### 2.1 공정시장가액비율

| 구분 | 공시가격 | 비율 |
|---|---|---|
| 1세대1주택 특례 | 3억 이하 | 43% |
| | 3억 초과 ~ 6억 이하 | 44% |
| | 6억 초과 | 45% |
| 그 외 (다주택·법인 등) | — | 60% |

### 2.2 세율

**일반세율** — 아래 특례 대상이 아닌 모든 주택

| 과세표준 | 세율 | 누진공제 |
|---|---|---|
| 6,000만원 이하 | 0.10% | 0 |
| 6,000만원 초과 ~ 1.5억 이하 | 0.15% | 30,000 |
| 1.5억 초과 ~ 3억 이하 | 0.25% | 180,000 |
| 3억 초과 | 0.40% | 630,000 |

**1세대1주택 특례세율** — **공시가격 9억원 이하**인 1세대1주택만

| 과세표준 | 세율 | 누진공제 |
|---|---|---|
| 6,000만원 이하 | 0.05% | 0 |
| 6,000만원 초과 ~ 1.5억 이하 | 0.10% | 30,000 |
| 1.5억 초과 ~ 3억 이하 | 0.20% | 180,000 |
| 3억 초과 | 0.35% | 630,000 |

> **중요.** 특례세율은 **공시가격** 9억 이하 조건이지 과세표준 기준이 아니다.
> 종부세 과세대상(1주택 14억 초과)은 언제나 공시가 9억을 넘으므로
> **종부세가 붙는 주택에는 특례세율이 적용되지 않는다.** (golden-cases H6 경계 참조)

### 2.3 부가세

| 항목 | 산식 |
|---|---|
| 지방교육세 | 재산세 **본세** × 20% |
| 도시지역분 | 재산세 **과세표준** × 0.14% |

```
재산세 합계 = round(본세) + round(지방교육세) + round(도시지역분)
```

곱하는 대상이 다르다. 지방교육세는 본세에, 도시지역분은 과세표준에 곱한다.

### 2.4 재산세 세부담 완화 — ⚠️ **둘 다 미구현** (2026-08-05 조문 확인)

**우리는 재산세를 `공시가격 × 공정시장가액비율 × 세율`로만 계산한다. 완화 장치가 하나도 없다.**
지방세법에는 **두 개의 서로 다른 제도**가 있고, 적용 순서가 정해져 있다.

#### ① 과세표준 상한 — 지방세법 §110③

과세표준 단계에서 제한한다. `260804 3단계프로그램.xlsx` `보유` D8이 이것을 구현한다:

```excel
D8 (올해)  =MIN(D6*D7, D16*D7 + D6*D7*5%)      ← D16 = 직전연도 과세표준
M8 (내년)  =ROUNDDOWN(M6*M7, 0)                 ← ⚠️ 엑셀도 내년 열에는 상한이 없다
```

**존재 근거는 종부세법 시행령 §5① 제1호가 명시적으로 인용한다** (2026-08-05 법제처 API 확인):

> 「지방세법」에 따라 부과된 재산세액(같은 법 제112조제1항제1호에 따른 재산세액을 말하며,
> 같은 법 **제110조제3항에 따라 과세표준상한이 적용되는 경우에는 그 상한을 적용한 후의 세액**을
> 말한다)

#### ② 세액 상한 — 지방세법 §122

산출세액 단계에서 제한한다. 조문 전문:

> 해당 재산에 대한 재산세의 **산출세액**(**제112조제1항 각 호 및 같은 조 제2항에 따른
> 각각의 세액**을 말한다)이 대통령령으로 정하는 방법에 따라 계산한 직전 연도의 해당 재산에 대한
> 재산세액 상당액의 **100분의 150**을 초과하는 경우에는 100분의 150에 해당하는 금액을 해당 연도에
> 징수할 세액으로 한다. **다만, 주택의 경우에는…**

**"각각의 세액"이 핵심이다.** §112①은 제1호가 일반 재산세액, 제2호가 도시지역분이다.
합산이 아니라 **본세와 도시지역분에 각각 따로** 상한을 건다.

실측으로도 확인된다 — 부동산계산기.com이 공시 25억·전년세액 261만에서
`세부담상한 3,393,000 (전년도 세액의 130%)`을 표시하고, 해설에서 도시지역분 상한
`1,638,000`을 따로 언급한다 ([budongsan-calculator-analysis.md §3-b](./budongsan-calculator-analysis.md)).
주택 단서의 구간별 비율과 `직전 연도 재산세액 상당액` 계산식은 **지방세법 시행규칙 §64의2**에 있다.

#### 적용 순서

시행령 §5① 제1호가 *"과세표준상한이 적용되는 경우에는 **그 상한을 적용한 후의 세액**"*이라고
하므로 **① 과세표준상한 → ② 세율 적용 → ③ 세액상한** 순이다.

#### 어느 원천도 완전하지 않다

| | §110③ 과세표준상한 | §122 세액상한 |
|---|---|---|
| 실무 엑셀 | ✅ D8 (단, M8 누락) | ❌ 없음 |
| 부동산계산기.com | 미확인 | ✅ |
| **우리** | ❌ | ❌ |

**개편안 PDF에는 둘 다 없다** — 250쪽 전문에서 `과세표준상한` 0회이고, 개편안은 재산세를
개정하지 않는다. 그래서 개편안을 근거로 쓴 이 명세에서 빠졌고, PDF 대조가 임무였던 독립 검증
([tax-verification-2026-08-05.md](./tax-verification-2026-08-05.md))도 범위 밖이라 못 잡았다.
**검증이 부실했던 게 아니라 검증 범위가 PDF였기 때문이다.**

**영향.** 공시가격이 크게 오른 주택에서 재산세가 실제보다 크게 나온다.
종부세 세부담상한(§5.1)과는 별개다 — 그쪽은 종부세, 이쪽은 재산세다.

**상태** 미구현. 구현 전 시행규칙 §64의2의 계산식과 주택 단서의 구간별 비율을 확보할 것.
[이슈 #2](https://github.com/hoddukzoa12/incometax/issues/2)

## 3. 종합부동산세

개인 주택분만 다룬다. **법인·토지분은 범위 밖**이다.

### 3.1 과세대상 기준 (p60, '27년~ 신설)

공시가격 **합계액**이 아래를 **초과**할 때만 납세의무가 생긴다.

| 구분 | 현행('26) | '27년~ |
|---|---|---|
| 1세대1주택자 | 12억 | **14억** |
| 그 외 | 9억 | 9억 |

### 3.2 기본공제 (p61, '27년~)

| 구분 | 현행('26) | '27년~ |
|---|---|---|
| 1세대1주택 · 거주 | 12억 | **14억** |
| 1세대1주택 · 비거주 | 12억 | **9억** |
| 그 외 | 9억 | **4억 + 5억 × (거주주택 공시가격 ÷ 주택 공시가격 합계액)** |

> **과세대상 기준과 기본공제는 별개 값이다.** '27년 1세대1주택 비거주자는
> 과세기준 14억 / 공제 9억이라 9~14억 구간에 공백이 생기고 14억에서 불연속이 발생한다.
> **개편안 그대로이므로 매끄럽게 만들지 말 것.** (golden-cases H4/H5)

> 다주택 공식에서 거주주택이 없으면 비중이 0이 되어 공제가 4억이 된다.

### 3.3 공정시장가액비율 (p62, '27년~)

| 구분 | 현행('26) | '27년 | '28년~ |
|---|---|---|---|
| 3주택 이상 **또는** 조정대상지역 주택 보유<br>(1세대1주택자는 제외) | 60% | 70% | **80%** |
| 그 외 (1세대1주택자 포함) | 60% | 70% | 70% |

> **1세대1주택자는 조정대상지역이어도 항상 70%다.** 조건 판정 순서를 틀리지 말 것.
> (golden-cases H8/H9/H10)

> **'27년 3주택 이상 세율표와 '28년 이후 일원화 세율표는 완전히 같다.**
> 개편이 "3주택 이상 세율로 통일"하는 방향이기 때문이다.
> **테이블을 두 번 적지 말고 하나를 참조하라** (R5). 값이 같다는 사실 자체를 주석으로 남길 것.

### 3.5 재산세 중복분 공제

```
공제액 = 종부세 과세표준 × 재산세 공정시장가액비율 × 0.4%
```

세율 0.4%는 재산세 **일반세율 최고구간**이다. §2.2 단서대로 종부세 대상 주택은
1주택 특례세율(0.35%) 구간에 들어가지 않으므로 항상 0.4%를 쓴다.

재산세 공정시장가액비율은 §2.1을 따른다 (1세대1주택 45%, 그 외 60%).

### 3.6 공동명의 지분 안분

**재산세와 종부세의 안분 시점이 다르다.** 이걸 통일하면 둘 다 틀린다.

| 세목 | 안분 시점 | 산식 |
|---|---|---|
| **재산세** | 세액 산출 **후** | 물건 전체 공시가격으로 과표·특례판정·본세·부가세를 산출한 뒤, **각 금액에** 지분율을 곱한다 |
| **종부세** | 과세표준 **전** | 공시가격에 **먼저** 지분율을 곱하고, 그 값을 개인별 합계에 넣는다. 공제·세율은 개인별 합계에 적용 |

재산세는 물건별 누진과세라 지분으로 먼저 나누면 낮은 세율 구간에 걸려 과소 계산된다.
종부세는 인별 과세라 각자 자기 지분만 소유한 것으로 보며, **그래서 기본공제도 각자 적용된다.**

### 3.7 주택 수 판정

**주택 수는 물건 단위이고 지분과 무관하다.** 공동명의 1채는 지분이 50%여도 **1주택**이다.
주택 수에 지분율을 곱하지 않는다.

이 판정이 좌우하는 것:
- 3주택 이상 여부 → '28년 공정시장가액비율 80% (§3.3)
- 1세대1주택 여부 → 과세대상 기준 14억 (§3.1), 기본공제 (§3.2)

#### 재산세와 종부세의 1주택 판정 기준이 다르다

H11이 드러낸 지점이다. **하나의 플래그로 두 판정을 담을 수 없다.**

| 세목 | 판정 | 근거 |
|---|---|---|
| **재산세** | 세대가 1주택을 소유 | 세대 기준. 지분이 어떻게 갈리든 무관 |
| **종부세** | 세대가 1주택 소유 **AND** 세대원 중 1명만 소유 | 종부세법: 세대원 중 **1명만이** 1주택만을 소유 |

종부세 판정이 **더 좁다.** 부부 공동명의 1채는 재산세로는 1세대1주택(45% 특례 유지)이지만,
종부세로는 세대원 2명이 소유하므로 1세대1주택자가 아니다(기본공제 9억).

#### 입력과 유도

**세대 구성은 엔진이 알 수 없으므로 사실을 입력받고, 두 판정은 유도한다.**

```
입력 (caller 제공)
  householdHomeCount   : 세대가 소유한 주택 물건 수
  isSoleHouseholdOwner : 물건별 — 세대원 중 본인만 소유하는가

유도 (입력받지 않는다)
  재산세 1세대1주택 특례  = householdHomeCount === 1
  종부세 1세대1주택자     = householdHomeCount === 1 && isSoleHouseholdOwner
```

**두 판정을 각각 입력받지 않는다.** 같은 사실에서 결정론적으로 유도되므로, 따로 받으면
법적으로 불가능한 조합(종부세는 1세대1주택자인데 재산세는 아님)이 표현 가능해진다.
같은 사실을 두 곳에 두는 것이므로 R5 위반이기도 하다.

> **`isSoleHouseholdOwner`를 `지분 === 1`에서 유도하지 않는다.** 대개 일치하지만,
> **세대 밖 공동소유자**가 있으면 지분이 1 미만이면서도 세대 내 유일 소유자일 수 있다.
> 별도 입력으로 받는다.

> ⚠️ **부부 공동명의 1주택 특례(종부세법 §10의2)는 P7까지 구현하지 않는다.**
> 지분이 큰 배우자가 주택 전체를 소유한 것으로 보아 1세대1주택 공제와
> 고령자·장기보유 세액공제를 받는 선택권인데, **그 세액공제가 P7**이다.
> 반쪽만 구현하면 잘못된 유불리 비교가 나온다. 부분 구현 금지.

### 3.8 농어촌특별세

```
농특세 = (종부세 본세 − 재산세 공제) × 20%
종부세 합계 = round(본세 − 재산세 공제) + round(농특세)
```

| 기간 | 현행 보유공제 | 개정 보유공제 | 개정 거주공제 |

### 5.2-a 거주기간 인정 특례 — 종부세 (p91–92, '27.1.1. 성립분~)

> **§5.2가 보유공제를 거주공제로 바꾼 개편의 짝이다.** 개정이유가 *"거주기간에 따른
> 공제로의 개편에 따른 제도 합리화"*다. 본체만 넣고 이걸 빼면 **거주를 못 한 정당한
> 사유가 있는 1주택자에게 실제보다 큰 세액**이 나온다.

**① 부득이한 사유 주거이전 — 보유기간을 거주기간으로 인정 (최대 3년)** (p91)

요건 ➊~➌ **모두** 충족:

| | 요건 |
|---|---|
| ➊ | 주거이전하는 날 현재 **1년 이상 계속하여 거주 중**인 주택 |
| ➋ | 부득이한 사유 발생 (아래) |
| ➌ | **타 시·군**으로 주거이전. 세대원 전원 또는 일부 |

부득이한 사유 — 고등·대학교 취학 / 직장변경·전근 등 근무상 형편 / **1년 이상**
치료·요양을 필요로 하는 질병의 치료 또는 요양 / 학교폭력 피해로 인한 전학 /
국외거주를 필요로 하는 취학 또는 근무상 형편으로 인한 출국 / **60세 이상** 직계존속
동거봉양 위한 합가 / 그 밖에 유사한 사유로서 부득이한 사유로 인정되는 경우

➌의 "타 시·군"에는 광역시 내 **구지역 ↔ 읍·면지역** 이전, 특별자치시·도농복합형태
시지역 ↔ 읍·면지역, 제주자치도 내 행정시의 **동지역 ↔ 읍·면지역** 이전을 포함한다.
국외거주 출국은 **해외로 주거이전**한 경우다.

**② 재개발·재건축 등 신축주택 공사기간의 50%를 거주기간으로 인정** (p92)

- 대상주택: **관리처분계획인가일 현재 1년 이상 계속 거주 중**인 주택
  (인가일 전 철거한 경우 **철거일로부터 소급하여 6개월이 되는 날** 기준)
- 공사기간: 관리처분계획인가일 ~ **신축주택 입주가능일**
- 인정분 = 공사기간 × **50%**

> ⚠️ **인정된 거주기간은 공제율 산정에만 쓴다.** PDF가 매 항목 말미에 같은 단서를 단다:
> *"거주기간 인정은 공제율 산정 시에만 적용. 1세대1주택 우대공제 요건 및 취득 당시
> 조정대상지역 소재 주택의 1세대1주택 비과세 요건인 2년 거주요건에는 미적용"*
>
> 즉 **자격 판정에는 쓰지 않는다.** 인정 3년을 더해 6년이 되어도 그것으로
> 2년 거주요건을 충족시키지 못한다. 이 구분을 흐리면 비과세 판정이 통째로 틀린다.

## 6. 계산 순서

```
보유세
  1. 주택별 재산세 = round(본세) + round(지방교육세) + round(도시지역분)
       ※ 물건 전체 공시가격으로 산출한 뒤 각 금액에 지분율을 곱한다 (§3.6)
  2. 재산세 합계 = Σ 주택별 재산세
  3. 주택별 공시가격 × 지분율 → 개인별 공시가격 합계 (§3.6)
       ※ 주택 수는 지분과 무관하게 물건 단위로 센다 (§3.7)
  4. 개인별 공시가격 합계가 과세대상 기준 이하면 → 종부세 0, 종료
  5. 종부세 과세표준 = (개인별 공시가격 합계 − 기본공제) × 공정시장가액비율
  6. 종부세 본세 = bracket(과세표준)
  7. 재산세 공제 차감 → 농특세 20% 가산
  8. 보유세 총액 = 재산세 합계 + 종부세 합계

양도소득세
  1. 양도차익 = 양도가액 − 취득가액 − 필요경비   (≤0이면 종료)
  2. 1세대1주택 비과세 판정 (12억 이하 + 2년 보유)
  3. 고가주택 안분 → 과세대상 양도차익
  4. 장특공제율 결정 → 공제액 산출 → 한도 적용
  5. 기본공제 차감 → 과세표준
  6. 보유기간에 따라 단일세율(70/60%) 또는 기본세율 적용
  7. 지방소득세 10% 가산
```
