# 세법 룰 명세

`src/rules/`가 담아야 할 값과 구조를 정의한다. **이 문서가 세법 값의 출처다** —
Codex는 개편안 PDF를 직접 뒤지지 말고 여기를 옮긴다.

기대값은 [golden-cases.md](./golden-cases.md)에 있다. 규칙은 [AGENTS.md](../AGENTS.md).

> **근거** 2026년 세제개편안 상세본 (재정경제부, '26.8.3.).
> 이하 `p57` 등은 **문서 페이지**이며, PDF 페이지 = 문서 페이지 + 13이다.
>
> **개편안은 국회 통과 전 정부안이다.** 심의 과정에서 바뀔 수 있으므로 연도별로 분리해
> 관리하고, 확정 시 이 문서를 먼저 고친 뒤 코드를 따라 고친다.

## 1. 설계 원칙

### 조건은 키로, 값은 테이블로 (R1)

세법 분기를 `if`로 표현하지 않는다. 조건 조합을 키로 만들어 테이블을 조회한다.

```ts
type HouseholdKind = 'oneHouse' | 'multiHouse'   // 1세대1주택자 여부
type Residency     = 'residing' | 'nonResiding'  // 해당 주택 거주 여부
type AreaKind      = 'adjusted' | 'general'      // 조정대상지역 여부
type TaxYear       = 2026 | 2027 | 2028 | 2029   // 2026 = 현행
```

### 값에는 출처를 단다 (R2)

근거 없는 숫자는 리뷰 반려다.

```ts
/** 종부세 기본공제 — 개편안 p61, '27.1.1. 이후 납세의무 성립분부터 */
export const BASIC_DEDUCTION_2027 = { /* ... */ } as const
```

### 누진세율 표현

모든 세율표는 동일한 형태를 쓴다. `누진공제`를 미리 계산해 둔다.

```ts
interface Bracket {
  upTo: number                  // 이 값 이하 구간 (최상단은 Infinity)
  rate: number                  // 세율 (0.007 = 0.7%)
  progressiveDeduction: number  // 누진공제액 (원)
}
// 세액 = max(0, 과세표준 × rate − progressiveDeduction)
```

## 2. 재산세 — **개편 대상 아님**

개편안에 재산세 개정 내용이 없다. 현행 지방세법이 '26~'29년 전 기간에 그대로 적용된다.

> ⚠️ 아래 값은 개편안이 아니라 **현행 지방세법**에서 온 것이다. 수치 자체는
> propertytax.co.kr 운영 서버 응답과 대조해 검증했으나(golden-cases H1),
> **조문 번호는 별도 확인이 필요**하다. 구현 시 조문을 인용하려면 법령을 직접 확인할 것.

### 2.1 공정시장가액비율

| 구분 | 공시가격 | 비율 |
|---|---|---|
| 1세대1주택 특례 | 3억 이하 | 43% |
| | 3억 초과 ~ 6억 이하 | 44% |
| | 6억 초과 | 45% |
| 그 외 (다주택·법인 등) | — | 60% |

### 2.2 세율

**일반세율** — 아래 특례 대상이 아닌 모든 주택

| 과세표준 | 세율 | 누진공제 |
|---|---|---|
| 6,000만원 이하 | 0.10% | 0 |
| 6,000만원 초과 ~ 1.5억 이하 | 0.15% | 30,000 |
| 1.5억 초과 ~ 3억 이하 | 0.25% | 180,000 |
| 3억 초과 | 0.40% | 630,000 |

**1세대1주택 특례세율** — **공시가격 9억원 이하**인 1세대1주택만

| 과세표준 | 세율 | 누진공제 |
|---|---|---|
| 6,000만원 이하 | 0.05% | 0 |
| 6,000만원 초과 ~ 1.5억 이하 | 0.10% | 30,000 |
| 1.5억 초과 ~ 3억 이하 | 0.20% | 180,000 |
| 3억 초과 | 0.35% | 630,000 |

> **중요.** 특례세율은 **공시가격** 9억 이하 조건이지 과세표준 기준이 아니다.
> 종부세 과세대상(1주택 14억 초과)은 언제나 공시가 9억을 넘으므로
> **종부세가 붙는 주택에는 특례세율이 적용되지 않는다.** (golden-cases H6 경계 참조)

### 2.3 부가세

| 항목 | 산식 |
|---|---|
| 지방교육세 | 재산세 **본세** × 20% |
| 도시지역분 | 재산세 **과세표준** × 0.14% |

```
재산세 합계 = round(본세) + round(지방교육세) + round(도시지역분)
```

곱하는 대상이 다르다. 지방교육세는 본세에, 도시지역분은 과세표준에 곱한다.

## 3. 종합부동산세

개인 주택분만 다룬다. **법인·토지분은 범위 밖**이다.

### 3.1 과세대상 기준 (p60, '27년~ 신설)

공시가격 **합계액**이 아래를 **초과**할 때만 납세의무가 생긴다.

| 구분 | 현행('26) | '27년~ |
|---|---|---|
| 1세대1주택자 | 12억 | **14억** |
| 그 외 | 9억 | 9억 |

### 3.2 기본공제 (p61, '27년~)

| 구분 | 현행('26) | '27년~ |
|---|---|---|
| 1세대1주택 · 거주 | 12억 | **14억** |
| 1세대1주택 · 비거주 | 12억 | **9억** |
| 그 외 | 9억 | **4억 + 5억 × (거주주택 공시가격 ÷ 주택 공시가격 합계액)** |

> **과세대상 기준과 기본공제는 별개 값이다.** '27년 1세대1주택 비거주자는
> 과세기준 14억 / 공제 9억이라 9~14억 구간에 공백이 생기고 14억에서 불연속이 발생한다.
> **개편안 그대로이므로 매끄럽게 만들지 말 것.** (golden-cases H4/H5)

> 다주택 공식에서 거주주택이 없으면 비중이 0이 되어 공제가 4억이 된다.

### 3.3 공정시장가액비율 (p62, '27년~)

| 구분 | 현행('26) | '27년 | '28년~ |

| 3주택 이상 **또는** 조정대상지역 주택 보유<br>(1세대1주택자는 제외) | 60% | 70% | **80%** |
| 그 외 (1세대1주택자 포함) | 60% | 70% | 70% |

> **1세대1주택자는 조정대상지역이어도 항상 70%다.** 조건 판정 순서를 틀리지 말 것.

### 3.5 재산세 중복분 공제

```
공제액 = 종부세 과세표준 × 재산세 공정시장가액비율 × 0.4%
```

세율 0.4%는 재산세 **일반세율 최고구간**이다. §2.2 단서대로 종부세 대상 주택은
1주택 특례세율(0.35%) 구간에 들어가지 않으므로 항상 0.4%를 쓴다.

재산세 공정시장가액비율은 §2.1을 따른다 (1세대1주택 45%, 그 외 60%).

### 3.6 공동명의 지분 안분

**재산세와 종부세의 안분 시점이 다르다.** 이걸 통일하면 둘 다 틀린다.

| 세목 | 안분 시점 | 산식 |
|---|---|---|
| **재산세** | 세액 산출 **후** | 물건 전체 공시가격으로 과표·특례판정·본세·부가세를 산출한 뒤, **각 금액에** 지분율을 곱한다 |
| **종부세** | 과세표준 **전** | 공시가격에 **먼저** 지분율을 곱하고, 그 값을 개인별 합계에 넣는다. 공제·세율은 개인별 합계에 적용 |

재산세는 물건별 누진과세라 지분으로 먼저 나누면 낮은 세율 구간에 걸려 과소 계산된다.
종부세는 인별 과세라 각자 자기 지분만 소유한 것으로 보며, **그래서 기본공제도 각자 적용된다.**

### 3.7 주택 수 판정

**주택 수는 물건 단위이고 지분과 무관하다.** 공동명의 1채는 지분이 50%여도 **1주택**이다.
주택 수에 지분율을 곱하지 않는다.

이 판정이 좌우하는 것:
- 3주택 이상 여부 → '28년 공정시장가액비율 80% (§3.3)
- 1세대1주택 여부 → 과세대상 기준 14억 (§3.1), 기본공제 (§3.2)

#### 재산세와 종부세의 1주택 판정 기준이 다르다

H11이 드러낸 지점이다. **하나의 플래그로 두 판정을 담을 수 없다.**

| 세목 | 판정 | 근거 |
|---|---|---|
| **재산세** | 세대가 1주택을 소유 | 세대 기준. 지분이 어떻게 갈리든 무관 |
| **종부세** | 세대가 1주택 소유 **AND** 세대원 중 1명만 소유 | 종부세법: 세대원 중 **1명만이** 1주택만을 소유 |

종부세 판정이 **더 좁다.** 부부 공동명의 1채는 재산세로는 1세대1주택(45% 특례 유지)이지만,
종부세로는 세대원 2명이 소유하므로 1세대1주택자가 아니다(기본공제 9억).

#### 입력과 유도

**세대 구성은 엔진이 알 수 없으므로 사실을 입력받고, 두 판정은 유도한다.**

```
입력 (caller 제공)
  householdHomeCount   : 세대가 소유한 주택 물건 수
  isSoleHouseholdOwner : 물건별 — 세대원 중 본인만 소유하는가

유도 (입력받지 않는다)
  재산세 1세대1주택 특례  = householdHomeCount === 1
  종부세 1세대1주택자     = householdHomeCount === 1 && isSoleHouseholdOwner
```

**두 판정을 각각 입력받지 않는다.** 같은 사실에서 결정론적으로 유도되므로, 따로 받으면
법적으로 불가능한 조합(종부세는 1세대1주택자인데 재산세는 아님)이 표현 가능해진다.
같은 사실을 두 곳에 두는 것이므로 R5 위반이기도 하다.

> **`isSoleHouseholdOwner`를 `지분 === 1`에서 유도하지 않는다.** 대개 일치하지만,
> **세대 밖 공동소유자**가 있으면 지분이 1 미만이면서도 세대 내 유일 소유자일 수 있다.
> 별도 입력으로 받는다.

> ⚠️ **부부 공동명의 1주택 특례(종부세법 §10의2)는 P7까지 구현하지 않는다.**
> 지분이 큰 배우자가 주택 전체를 소유한 것으로 보아 1세대1주택 공제와
> 고령자·장기보유 세액공제를 받는 선택권인데, **그 세액공제가 P7**이다.
> 반쪽만 구현하면 잘못된 유불리 비교가 나온다. 부분 구현 금지.

### 3.8 농어촌특별세

```
농특세 = (종부세 본세 − 재산세 공제) × 20%
종부세 합계 = round(본세 − 재산세 공제) + round(농특세)
```

## 4. 양도소득세

### 4.2 단기보유 중과세율 (현행)

| 보유기간 | 세율 |
|---|---|
| 1년 미만 | 70% (단일세율) |

### 4.3 1세대1주택 비과세와 고가주택 안분

```
비과세 요건: 양도가액 12억 이하 + 보유 2년 이상
고가주택 안분: 과세대상 양도차익 = 양도차익 × (양도가액 − 12억) ÷ 양도가액
```

> **보유 2년 미만이면 비과세 요건 자체를 못 채우므로 안분 없이 전액 과세된다.**
> (golden-cases T7)

> ⚠️ **미반영.** 조정대상지역에서 취득한 주택은 2년 **거주** 요건이 추가된다.
> P4에서 `adjusted-areas` 도입 후 반영한다. 그때까지는 비조정 전제다.

### 4.4 장기보유특별공제 (p56~58)

'28년 양도분부터 **장기거주소득공제**(주택·조합원입주권)와
**장기보유소득공제**(토지·주택 외 건물)로 이원화된다 (p56). 주택은 전자만 적용된다.

**1세대1주택** (p57) — 기본요건: **3년 이상 보유 + 2년 이상 거주**

| 양도 시점 | 거주공제 | 보유공제 | 합계 한도 |
|---|---|---|---|
| ~'27.12.31. | 연 4% (최대 40%) | 연 4% (최대 40%) | 80% |
| '28.1.1.~'28.12.31. | 연 **6%** (최대 60%) | 연 **2%** (최대 20%) | 80% |
| '29.1.1.~ | 연 **8%** (최대 80%) | **폐지** | 80% |

**다주택자 주택** (p58) — 기본요건: **3년 이상 보유**

| 양도 시점 | 적용 방식 | 거주공제 | 보유공제 | 합계 한도 |
|---|---|---|---|---|
| ~'27.12.31. | 보유공제만 | — | 연 2% (최대 30%) | 30% |
| '28.1.1.~'28.12.31. | **둘 중 높은 쪽** | 연 2% (최대 30%) | 연 **1%** (최대 15%) | 30% |
| '29.1.1.~ | 거주공제만 | 연 2% (최대 30%) | **폐지** | 30% |

> **거주공제는 2년 이상 거주 시에만 적용된다** (p58 각주). 거주 1년이면 0%다.

> ⚠️ **해석 필요.** 1세대1주택인데 거주 2년 미만이면 p57 기본요건을 못 채운다.
> 이때 어느 표를 적용할지 개편안 문언이 명확하지 않다.
> **현재 해석: 다주택자 표(p58)로 내려온다.** golden-cases T2가 이 해석을 따른다.
> 다르게 판단해야 한다면 반드시 `ask`할 것.

### 4.5 장특공제 한도 (p59, '28년 양도분부터 신설)

**➊ 인별 연간**과 **➋ 양도물건별**에 **각각** 적용한다.

| 양도 시점 | 인별 연간 한도 | 양도물건별 한도 |
|---|---|---|
| '28년 | 20억 | 20억 |
| '29년~ | 10억 | 10억 |

공동소유이거나 시점을 달리해 분할양도하는 경우 **지분 비율 또는 분할양도 비율로
안분**해 한도를 적용한다.

> **표시 주의.** 한도가 걸리면 화면의 공제율은 **한도 적용 후 실효율**이어야 한다.
> 산출 공제율(80% 등)을 그대로 표시하면 오류다 (golden-cases T4).

### 4.6 양도소득 기본공제 (p68, **'27년 양도분부터**)

| 구분 | 공제액 |
|---|---|
| 기본 | 연 250만원 |
| **10년 이상 거주 + 양도가액 30억 이하 1세대1주택** | 연 **2,500만원** |

- 250만원 **초과분은 해당 1주택 양도분에서만** 공제
- 인별·양도물건별로 안분 적용 (**부부 공동명의는 각각 적용**)
- 특수관계인 간 양도, 비거주자는 적용 제외

> **적용시기가 '27년이다.** '28년으로 걸면 '27년 세액이 과대 계산된다
> (기존 서비스의 오류, golden-cases T1).

```
총세액 = round(본세) + round(지방소득세)
```

## 6. 계산 순서

```
보유세
  1. 주택별 재산세 = round(본세) + round(지방교육세) + round(도시지역분)
       ※ 물건 전체 공시가격으로 산출한 뒤 각 금액에 지분율을 곱한다 (§3.6)
  2. 재산세 합계 = Σ 주택별 재산세
  3. 주택별 공시가격 × 지분율 → 개인별 공시가격 합계 (§3.6)
       ※ 주택 수는 지분과 무관하게 물건 단위로 센다 (§3.7)
  4. 개인별 공시가격 합계가 과세대상 기준 이하면 → 종부세 0, 종료
  5. 종부세 과세표준 = (개인별 공시가격 합계 − 기본공제) × 공정시장가액비율
  6. 종부세 본세 = bracket(과세표준)
  7. 재산세 공제 차감 → 농특세 20% 가산
  8. 보유세 총액 = 재산세 합계 + 종부세 합계

양도소득세
  1. 양도차익 = 양도가액 − 취득가액 − 필요경비   (≤0이면 종료)
  2. 1세대1주택 비과세 판정 (12억 이하 + 2년 보유)
  3. 고가주택 안분 → 과세대상 양도차익
  4. 장특공제율 결정 → 공제액 산출 → 한도 적용
  5. 기본공제 차감 → 과세표준
  6. 보유기간에 따라 단일세율(70/60%) 또는 기본세율 적용
  7. 지방소득세 10% 가산
```
