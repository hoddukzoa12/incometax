### ❌ 확인된 불일치 두 건

개편안 원문을 직접 확인했다 (문서 p63–64 / PDF p76–77).

**(1) 1세대1주택 종부세 세율이 현행 값이다.**

원문 개정 취지가 *"주택수 기준 차등세율 단계적 폐지 및 과세표준 6~12억원 구간 세율 인상"*이고,
세율표는 **`2주택 이하` / `3주택 이상` 두 갈래로만** 나뉜다. **`1세대1주택` 세율표는 없다.**

```
'27년  2주택 이하 :  3억 0.5 / 6억 0.7 / 12억 1.3 / 25억 1.5 / 50억 2.0 / 94억 2.7 / 3.5
현행   2주택 이하 :  3억 0.5 / 6억 0.7 / 12억 1.0 / 25억 1.3 / 50억 1.5 / 94억 2.0 / 2.7
                                        ↑ 엑셀 1세대1주택 열이 이 표를 쓴다
```

1세대1주택자도 1주택이므로 '27년부터 **`2주택 이하` 표(1.3% …)를 쓴다.**
엑셀 M열은 현행 표라 **6~12억 구간에서 0.3%p, 그 위로 계속 낮게 나온다.**

**(2) 세액공제 금액 한도가 800만원 고정이다.**

p64 원문: *"(금액한도) ('27년) 800만원 → ('28년 이후) 600만원"*.
엑셀은 `MIN(8000000, ...)`로 연도 구분이 없다. **'28년 계산에서 과다공제된다.**

> 나머지는 전부 개편안과 일치한다 — 공정시장가액비율 70%/80%, 공제 14억/9억,
> 다주택 공제 공식, 보유·거주·연령 공제율, `MAX(보유,거주)+연령` 구조, 80% 상한,
> 세부담상한 200%. **시트는 개편안 기준으로 작업 중이고 위 두 곳이 미갱신으로 보인다.**
> 다만 세무사의 의도적 판단일 가능성을 배제할 수 없어 **사용자 확인 대상으로 둔다** (§7).

### 6.3 자산 유형 — 좌측 사이드바로 구분한다 (2026-08-05 사용자 방향)

> **"현재 주택만 하였잖아. 추후, 좌측 사이드바에 주택·토지·상가·건물 등 구분하는 게

**결론 — 지금 코드에 반영할 것과 미룰 것**

[AGENTS.md §4](../AGENTS.md)의 `AssetKind`는 `apartment | detachedHouse` + P8 `commercial | land`다.
**타입 정의는 넓히되, 세율 테이블·판정 로직은 만들지 않는다** (§4의 과잉 추상화 금지).

```ts
type AssetKind =
  | 'apartment' | 'detachedHouse'    // 주택 — 현재 지원
  | 'commercial'                     // 상가·오피스텔 (건축물)
  | 'land'                           // 토지
// 토지는 land 하나로 부족하다. 재산세·종부세 구분이 세율을 가른다:
type LandTaxCategory = 'aggregate' | 'separateAggregate' | 'separate'
//                     종합합산      별도합산              분리과세
// 농지·자경농지는 분리과세 토지의 하위 구분이지 별도 AssetKind가 아니다
```

**농지·자경농지를 별도 `AssetKind`로 두지 않는다.** 재산세에서는 분리과세 토지의
세율 구분(0.07%)이고, 자경 여부는 양도세 감면 요건이다. **성격이 다른 두 축을
하나의 열거형에 섞으면 R1(중첩 조건문 객체화)을 위반한다.**

**우선순위 재검토가 필요하다.** 세무법인 리치 주력이 **토지수용·보상**이다(§5.1).
현재 로드맵은 토지를 P8(착수 시점 미정)에 두는데, 이 전제라면 너무 뒤다. → §7

### 6.4 특수관계인 · 증여추정 — 없다

엑셀 `0 기초` 시트 F1에 `특수관계인 증여추정`이 있고 배우자·자녀·부모까지 열이 잡혀 있다.
우리 명세에는 §3.7 주택 수 판정에서 "세대"를 다룰 뿐, 특수관계인 간 거래 판정은 없다.

### 6.5 소유자가 여럿이다

엑셀 `보유` 시트는 **소유자1 / 소유자2**를 나란히 계산한다 (종부세는 인별 과세).
우리는 지분 안분(§3.6)은 있으나 "한 화면에서 세대 구성원 여러 명"을 다루지 않는다.

### 6.6 입력 모드 세 가지

엑셀 A1~A4: `목록선택` / `전년도 연동` / `예상치 기입` / `수기기입`.
자산별로 **예상증가율을 각각** 지정한다 (주택1 5%, 주택2 6%, 토지 7% …).
호갱노노는 단일 증감률 하나였다 — 이쪽이 더 정밀하다.

## 7. 미결

### ✅ 결정 — A안 (깊이 우선), 2026-08-05

```
주택: 보유(P4) → 양도(P5) → 취득(P9)   ...주택 3단계 완결 후 → 토지·상가(P8)
```

주택 사용자에게 완결된 가치를 먼저 준다. 너비 우선(B안 — 보유세를 주택→건축물→토지로
확장)은 채택하지 않는다.

**따라 나오는 것 셋:**

| 미결이었던 것 | 결정 |
|---|---|
| 취득세를 어디에 끼우는가 | **P9 신설, P5 다음 · P6 앞** (Wave 4) |
| 토지·상가 우선순위 | **P8 유지** — 주택 3단계 완결 후 |
| 좌측 사이드바 시점 | **P8과 함께.** 그전에는 탭이 하나뿐이라 의미가 없다 |

> 토지수용·보상이 세무법인 주력(§5.1)이라 B안도 근거가 있었으나,
> 반쪽짜리 3단계를 여러 자산에 펼치는 것보다 한 자산을 끝내는 쪽을 택했다.

### 남은 미결

> **세무사 확인 항목은 [tax-accountant-questions.md](./tax-accountant-questions.md)로 옮겼다.**
> 질문 전문·근거·영향 금액이 거기 있다. 아래 표는 상태만 추적한다.

> **출처 우선순위 확정 (2026-08-05).** PDF가 1순위, 엑셀이 2순위다.
> PDF에 값이 있으면 PDF를 쓰고, PDF에 없는 것만 엑셀 해석을 따른다.
> 규칙 전문은 [tax-rules-spec.md §0](./tax-rules-spec.md).
> **이 규칙으로 §4의 불일치 두 건은 PDF 채택으로 정리됐다** — 세무사 확인은
> 참고용이며 착수를 막지 않는다.

| # | 내용 | 상태 |
|---|---|---|
| 1 | 엑셀 불일치 두 건 (§4) — 1세대1주택 세율, 800만원 한도 | ✅ **PDF 채택으로 확정** |
| 2 | 상담 연결 (§5) | **보류 — 서비스 직전에 착수** |
| 3 | 2026 개편안에 **취득세 개편이 있는가** | P9 착수 전 확인 |
| 4 | 면책 문구 (정부안·국회 통과 전) 표기 방식 | P4 착수 시 필요 |
| 5 | **세부담상한 기준액에 지방교육세·도시지역분이 들어가는가** | ✅ **엑셀 해석 채택** (PDF에 정의 없음). 세무사 답변 시 재검토 |
| 6 | **재산세 과세표준상한(105%) 산식** | ⚠️ **미구현.** 확인 후 P7-3 |

> **6번은 1·5번과 함께 물어보면 된다.** 세 건 다 PDF가 답하지 못하는 영역이다.
>
> 엑셀 `보유` D8이 `MIN(공시×비율, 전년과표×비율 + 공시×비율×5%)`로 상한을 거는데
> 우리는 상한 없이 곱한다. **공시가격이 크게 오른 주택에서 재산세가 실제보다 크게 나온다.**
> 개편안 PDF에 없는 현행 지방세법 사항이라 명세에서도, PDF 대조 검증에서도 빠졌다.
> 산식과 근거 조문은 [tax-rules-spec.md §2.4](./tax-rules-spec.md).

> **5번은 1번과 함께 물어보면 된다.** 질문을 이렇게 좁히면 된다 —
> *"세부담상한 기준액의 「재산세」에 지방교육세와 도시지역분이 포함됩니까?"*
>
> 개편안 원문은 비율(150%→200%)만 바꾸고 기준액 범위를 정의하지 않는다(문서 p65).
> 다만 **문서 p66 납부유예 요건은 "재산세 + 종합부동산세(부가세 포함)"라고 명시**한다.
> 같은 문서가 필요할 때 명시한다는 점에서 **지방교육세·농특세는 제외 쪽이 유력**하고,
> 이는 엑셀 해석과 일치한다. **도시지역분은 부가세가 아니라 여전히 미확정이다.**
> 근거 전문은 [golden-cases.md](./golden-cases.md) H14에 있고, 현재 구현은
> 엑셀 해석(본세만)으로 고정했다.
