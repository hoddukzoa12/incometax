# 세제 검증 보고서 — 2026-08-05 (Task D, 독립 검증)

검증 사슬: `docs/세제개편안.pdf` (재정경제부 '26.8.3.) → `docs/tax-rules-spec.md` →
`src/rules/*.ts` → `docs/golden-cases.md`. PDF는 직접 추출한 텍스트(250쪽)로 대조했다.
페이지 인용은 **문서 페이지** 기준 (PDF 페이지 = 문서 페이지 + 13).

## 결론 요약

**구현 범위 내 수치 오류는 발견되지 않았다.** 스펙에 있는 모든 개편 수치가 PDF 원문과
일치하고, 코드의 누진공제 48개 구간이 전수 산술 일치하며, 골든 케이스 H1~H14·T1~T7
전부가 손계산(스크립트)으로 1원 단위까지 재현된다.

찾은 것은 **오류가 아니라 공백**이다 — PDF에 있고 스펙이 다루지 않는 특례 규정 3묶음.
어느 쪽도 현재 계산 결과를 틀리게 하지 않지만, P7 구현 범위를 결정할 때 명시적으로
다뤄야 한다.

## Findings (영향 큰 순)

### F1. 종부세 거주공제·양도세 장기거주소득공제의 "거주기간 인정" 특례가 스펙에 없음 — SUSPECTED (범위 결정 필요)

- **PDF 문서 p91 (19)①**: 종부세 거주공제 적용 시 부득이한 사유(취학·근무·요양 등)로
  주거이전한 기간은 **보유기간을 거주기간으로 인정** (최장 3년). '27.1.1. 이후 납세의무
  성립분부터.
- **PDF 문서 p84~85 (18)①**: 동일 취지가 양도세 장기거주소득공제에도 신설.
  '28.1.1. 이후 양도분부터.
- **스펙**: §4.4, §5.2 어디에도 없음. 코드(`transfer-deductions.ts`,
  `comprehensive-tax-credit.ts`)에도 거주기간 보정 입력이 없다.
- **원화 차이 (구체 입력)**: 양도차익 4억 · 1세대1주택 · 보유 10년 · 실거주 7년 +
  부득이한 주거이전 3년인 경우 '29년 양도 시 — 인정 없으면 거주공제 8%×7 = 56%
  (공제 2.24억), 인정하면 8%×10 = 80% (공제 3.2억). **차이 9,600만원 공제**,
  세액으로는 약 4,200만원(40% 구간 가정). 종부세 쪽은 동일 조건에서 거주공제율
  20%→40%로, 산출세액 158만원(H12 유형) 기준 연 약 32만원.
- 해당자가 좁은 특례이므로 MVP 범위 밖으로 둘 수는 있으나, 스펙 §5 "P7 이전 미반영"
  목록에도 없어 **현재는 추적 자체가 안 되는 상태**다. 명시적 유보 기록을 권장.

### F2. 같은 특례의 나머지 인정 사유 — 특례주택·임대기간·재건축 공사기간 — SUSPECTED (범위 결정 필요)

- **PDF 문서 p86 (18)②**: 인구감소지역 주택 등 특례주택과 기존주택을 함께 보유한
  기간을 거주기간으로 인정 ('28년~).
- **PDF 문서 p87 (18)③**: 등록임대주택 임대기간을 거주기간으로 인정해 거주공제율
  일부 적용 (1주택 연 2% 최대 30%).
- **PDF 문서 p88 (18)④**: 재개발·재건축 공사기간의 50%를 거주기간으로 인정.
  **PDF 문서 p92 (19)②**: 종부세 쪽 동일.
- 원화 차이: 케이스에 따라 F1과 동일 구조로 수백만~수천만원. 임대·재건축은
  현재 입력 모델에 개념 자체가 없다.

### F3. 세부담상한 기준액의 "재산세" 범위 — PDF 침묵을 직접 확인 — CONFIRMED (PDF 침묵), 해석은 미확정

- **PDF 문서 p65**: 세부담상한 150%→200% 개정만 있고 기준액 정의는 없음을 원문으로
  확인했다. **문서 p66** 납부유예 조항이 "재산세+종합부동산세(부가세 포함)"라고
  **명시**하는 것과의 대조 해석(스펙 §0, 골든 H14)은 문언상 성립한다.
- 그러나 골든 H14가 이미 지적한 대로 **도시지역분은 부가세가 아니라 재산세
  도시지역분**이라 이 대조가 닿지 않는다. PDF 어디에도 답이 없다.
- **원화 차이 (H14 입력 그대로)**: 기준액에 전년 지방교육세 522,000 + 도시지역분
  1,134,000을 포함하면 상한이 7,764,000 → 11,076,000으로 올라 **상한 미발동**,
  '27년 총 보유세가 10,891,800 → 11,527,800. **차이 636,000원**. 엑셀 해석(본세만)
  유지가 현 상태이며 세무사 확인 질문으로 이미 좁혀져 있다 — 유지 권장.

### 코드 vs 스펙 — 일치 (CONFIRMED)

- `src/rules/2026~2029.ts`의 연도별 조립이 스펙 §3~§5와 정확히 대응한다.
  '27년 장특공제가 개편 전 표(`THROUGH_2027`)를 쓰는 것, 기본공제 특례만 '27년부터
  켜지는 것 등 적용시기 조합이 모두 옳다.
- **누진공제 전수 재계산 (48개 구간, 스크립트)**: 종부세 4개 표 28구간, 재산세 2개 표
  8구간, 양도세 기본세율 8구간 — 전부 `PD_i = PD_{i-1} + (rate_i − rate_{i-1}) × 경계`
  와 일치. 오류 0건.
- '27년 3주택 이상 = '28년 이후 표를 하나의 상수(`COMPREHENSIVE_TAX_REFORM_UNIFIED_BRACKETS`)로
  공유 — 스펙 지시대로이며 값도 PDF p63과 일치.

### 골든 케이스 — 전수 재현 (CONFIRMED)

- H1~H14, T1~T7 전부 독립 재계산(스크립트)으로 **1원 단위 일치**.
- 과거 오류가 잡혔던 H13 '28년 열(2.0% 일원화 표, 본세 23,800,000)은 현재 문서 값이
  정확하다. 재계산 결과 3,075,840 / 11,308,800 / 17,428,800으로 문서와 같다.
- H12(80% 상한→금액 한도 순서), H14(상한 530,000 초과, 총 10,891,800), T4(한도 10억
  발동 시 256,311,000, 본세·지방세 각각 반올림 규약과 일치) 등 코디네이터 산출 케이스도
  전부 재현된다.
- H4/H5 절벽(14억 기준·9억 공제의 불연속)은 PDF p60~61 그대로다.
