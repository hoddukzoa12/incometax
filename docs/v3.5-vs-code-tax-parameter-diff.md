# v3.5 엑셀 vs `src/rules` 세금 파라미터 비교

비교 대상은 `docs/3단계프로그램 v3.5.xlsx`의 11개 시트 전체와
`src/rules/property-tax.ts`, `comprehensive-tax.ts`,
`comprehensive-tax-credit.ts`, `comprehensive-tax-burden-cap.ts`,
`2026.ts`, `2027.ts`, `2028.ts`다. 숫자 표는 `t` 시트에서, 실제 적용 조건은
`공동보유`·`단독보유(부부특례)` 시트의 수식에서 확인했다.

## 차이 1 — 2027년 종부세 세율표 선택 조건

- 엑셀: 1세대1주택자가 아닌 사람이 조정대상지역 주택을 보유하면 주택 수가
  2채 이하이어도 `3주택`으로 분류해 2027년 3주택 세율표를 선택한다.
  근거 수식은 `공동보유!B4:C4`, `단독보유(부부특례)!B4`의
  `IF(AND(주택수<=2,지역<>"조정대상지역"),"비거주1주택","3주택")`이며,
  2027년 결과는 이 분류로 `J46:L61` 중 하나를 고른다.
- 코드: `COMPREHENSIVE_ELEVATED_HOME_COUNT_MINIMUM = 3`이고 2027년 세율표는
  주택 수가 3 이상일 때만 3주택 표를 쓴다. 따라서 조정대상지역 보유 여부와
  무관하게 2주택 이하는 `COMPREHENSIVE_TAX_BRACKETS_2027_UP_TO_TWO_HOMES`다.
- 차이가 나는 과표 구간은 12억 원 초과다.
  - 25억 원 이하: 엑셀 2.0%·누진공제 12,600,000원 / 코드 1.5%·6,600,000원
  - 50억 원 이하: 엑셀 3.0%·37,600,000원 / 코드 2.0%·19,100,000원
  - 94억 원 이하: 엑셀 4.0%·87,600,000원 / 코드 2.7%·54,100,000원
  - 94억 원 초과: 엑셀 5.0%·181,600,000원 / 코드 3.5%·129,300,000원
- 두 세율표 자체의 숫자는 일치하고, **적용 조건만 다르다**. 2026년은 양쪽 모두
  주택 수 기준이고, 2028년은 세율표가 일원화되어 이 차이가 없다.

## 차이 2 — 2027·2028년 종부세 과세대상 기준의 독립 적용

- 코드에는 기본공제와 별도로 과세대상 기준이 있다:
  1세대1주택 1,400,000,000원, 그 외 900,000,000원
  (`COMPREHENSIVE_TAXABLE_THRESHOLDS_FROM_2027`).
- 엑셀에는 이 독립 문턱이 없다. `공동보유`와 `단독보유(부부특례)` 모두
  2027년 `J48:L49`, 2028년 `R48:T49`에서 공시가격 합계와 기본공제만 비교한다.
  따라서 엑셀의 실질 과세 문턱은 기본공제와 같다:
  - 거주 1세대1주택: 1,400,000,000원
  - 비거주 1세대1주택: 900,000,000원
  - 다주택: `400,000,000원 + 500,000,000원 × 거주주택 공시가격 비중`
    (400,000,000원 이상 900,000,000원 이하)
- 결과적으로 2027·2028년에 비거주 1세대1주택 공시가격이 9억 원 초과 14억 원
  이하이면 엑셀은 종부세를 계산하지만 코드는 비과세 처리한다. 다주택자는 동적
  기본공제가 9억 원보다 작을 때 그 공제액 초과 9억 원 이하 구간에서 같은 차이가 난다.
- 기본공제 숫자 자체는 양쪽이 일치하며, **별도 과세대상 문턱의 존재 여부가 다르다**.

## 차이 3 — 2028년 이후 비활성 보유기간 공제 데이터

- 엑셀은 2028년부터 보유기간 공제 셀을 비워 두고 연령공제와 거주기간 공제만
  합산한다.
- 코드는 2028년 규칙 객체에도 보유 5년 10%, 10년 20%, 15년 25%를 담지만
  `periodCreditKind: 'residence'`로 두어 계산에는 사용하지 않는다.
- 이는 원시 룰 데이터의 표현 차이일 뿐, 유효 세액공제는 양쪽 모두 2028년부터
  연령공제 + 거주기간 공제이고 계산 결과 차이는 없다.

## 일치

재산세 세율표·누진공제, 재산세 공정시장가액비율, 재산세 과세표준상한율 5%,
종부세 2026/2027/2028 세율표와 모든 누진공제, 종부세 공정시장가액비율,
기본공제, 유효 연령·보유·거주 세액공제율과 합산율 상한 80%, 세액공제 금액한도
(2027년 8,000,000원, 2028년 6,000,000원), 세부담상한율
(2026년 150%, 2027·2028년 200%)은 일치한다.
